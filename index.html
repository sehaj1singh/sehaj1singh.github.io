A cable-driven robot that rides above terraced orchards. The farm is scanned into a Gaussian splat, and my job was turning that photoreal blur into things the robot can reason about: this tree, that apple, a path to it.

I built the 3D instance segmentation pipeline (SAM 3 masks lifted through 85 camera poses, identity resolved by mask overlap instead of tracking), made the C++/OpenGL renderer fast enough to use, swapped A* for Theta* pathfinding, and shipped a natural language command bar so an operator can type "send the robot to the tree with the most apples."
